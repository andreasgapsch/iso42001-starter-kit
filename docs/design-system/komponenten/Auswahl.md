# Auswahl

Auswahlliste für eine von mehreren festen Optionen, gestaltet wie das Eingabefeld.

**Verwendung:** ab fünf Optionen oder wenn der Platz knapp ist; bei zwei bis vier Optionen sind Optionsfelder oft klarer. Stufen einer Skala (Wahrscheinlichkeit, Auswirkung) zeigen Zahl und Bezeichnung: «3 möglich».

**Was Sie liefern:** `beschriftung`, `optionen` als `{ wert, text }`, den aktuellen `wert` und `onChange`; optional `platzhalter` («Bitte wählen»), `hinweis`, `fehler`, `pflicht`.

**Nicht:** Optionen ohne sichtbare Beschriftung; Mehrfachauswahl in diesem Element (dafür Kontrollkästchen).

Herkunft: für Applikationen ergänzt, Masse und Farben von `.feld` der Website; Pfeil aus zwei Linien in `tinte`.
