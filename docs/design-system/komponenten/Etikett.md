# Etikett

Kleines Etikett über einer Überschrift: Knoten, kurze Leitung, Text, statt eines «// LABEL».

**Verwendung:** ordnet eine Seite oder Karte ein («Etappe 6, Risiken und Chancen»). Knoten `knoten-klein` in `blau`, Leitung 1.6rem in `linie-stark`, Text .82rem, 620, `gedaempft`.

**Was Sie liefern:** den Text als `children`; optional `als` (Element, Standard `p`).

**Nicht:** Grossbuchstaben, Monospace, Schrägstriche; mehr als ein Etikett je Überschrift.

Herkunft: `.etikett` der Website.
