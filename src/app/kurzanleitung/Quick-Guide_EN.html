AIMS Manager: Quick guide

Tool of the ISO/IEC 42001 Starter Kit. One file that runs offline in your browser.

Your data does not leave this computer. Your information is kept in a project file with the extension .aims.json. Save it in a secure location, for example a folder that is backed up.

1. Getting started

  1. Open aims-manager.html with a double click (Edge, Chrome, Firefox or Safari).
  2. Choose New project, Open project file or an example.
  3. For a new project, choose the path (with or without an ISMS) and whether the EU AI Act module is included. You can change both in the settings.

2. Working

  • Navigation: on the left you choose the area (Start, Overview, Guide, Registers, Processes, Library, Knowledge, Check), next to it the page in the sub-menu. Each page shows its title, the search (/) and its main action at the top, for example ‘Add AI system’. On a phone the areas are at the bottom, the others under ‘More’.
  • Guide: stage by stage, one question per page. On the right you find help, an example answer, typical mistakes and references to the standard, template and guide.
  • Later: put pages aside without an answer; they appear among the open items.
  • Registers: all information at a glance (inventory, risks, SoA, actions, AI Act, 27001 bridge and more).
  • Questionnaire: in the AI inventory, send it to business units as an Excel file and import the completed files.

3. Saving

  • Save with Ctrl+S (Mac Cmd+S), with the save status next to the search or in the project menu at the bottom of the tool bar. Edge and Chrome write directly to the open file; Firefox and Safari download a new file to the downloads folder.
  • ‘Unsaved changes’ next to the search shows that the file is not up to date. The browser keeps an interim copy every two seconds; it does not replace the project file.

4. Checking and generating documents

  • Check (Alt+P): traffic light ‘Ready for Stage 1’, errors and notes with a jump to the right place.
  • Library: documents with status, version and review date. In Edge and Chrome you connect a folder of your choice; in Firefox and Safari the library stays in browser storage.
  • Generate documents (Library, Generate): the complete set as Word and Excel files (ZIP), individually or as a print view for PDF. The documents belong to your organization.

5. AI assistant

‘Go deeper with AI’ creates a request to copy; you can deselect confidential information first. Use the assistant's project file on the start page with ‘Use the result of the AI assistant’.

Good to know

  • Keyboard: Enter next, Alt+Shift+Left arrow back, Alt+P check. Choose the language and appearance (dark, light, like system) under Settings.
  • Windows: generated Word and Excel files first open in Protected View. Click ‘Enable Editing’.
  • On shared computers, clear the interim storage in the settings.
  • Printing: printouts show the organization, the date and, in Edge and Chrome, the page. In Firefox and Safari the print setting ‘Headers and footers’ adds page numbers, but also prints the address of the file.
